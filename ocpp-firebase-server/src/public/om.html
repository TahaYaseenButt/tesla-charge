📖 Complete Reference Guide: What You Can Control & How
Every supported hardware control, OCPP command, and API endpoint for your station
Feature / Capability What It Controls on the Charger How to Control It (UI or API) OCPP 1.6 Action / Key
Start / Stop Charging Starts or stops power delivery on Gun A (Connector 1) or Gun B (Connector 2). Use the Remote Start / Stop buttons above, Mobile App Control tab, or POST /api/chargers/:id/start & /stop RemoteStartTransaction
RemoteStopTransaction
Force Unlock Charging Gun Releases the electronic lock inside Gun A or Gun B if a plug is stuck. Click Unlock Gun A/B Cable above or POST /api/chargers/:id/unlock with {"connectorId": 1} UnlockConnector
Soft / Hard Reboot Soft: Restarts OCPP software process.
Hard: Full physical reboot of charger controller board.		 Click Soft Reboot or Hard Reboot above, or POST /api/chargers/:id/reset with {"type": "Soft"|"Hard"} Reset
Meter Sample Speed Controls how many seconds between live kW, Voltage, Current, and SoC updates during charging (currently 10s). In the Configuration table above, change MeterValueSampleInterval (e.g. 5 or 10) and click Apply. ChangeConfiguration
(MeterValueSampleInterval)
Heartbeat & Ping Speed Controls how frequently the charger sends keepalive signals to stay Online (currently 30s). In the Configuration table above, edit HeartbeatInterval or WebSocketPingInterval and click Apply. ChangeConfiguration
(HeartbeatInterval)
Offline RFID & Plug-and-Charge Allows charging to start automatically or via RFID card even if internet drops (LocalAuthorizeOffline, AllowOfflineTxForUnknownId). Toggle true / false on AllowOfflineTxForUnknownId or LocalAuthorizeOffline in the table above. ChangeConfiguration
Auto-Unlock When Car Stops Automatically unlocks the gun when the vehicle finishes or disconnects on EV side. Set UnlockConnectorOnEVSideDisconnect to true in the Configuration table above. ChangeConfiguration
Smart Power Limiting (kW Cap) Caps maximum DC output power (e.g., 30kW, 60kW, 120kW, 240kW) to prevent overloading solar/grid inverters. Click the Cap at 30/60/120/240 kW buttons in the Smart Charging panel above. SetChargingProfile
ClearChargingProfile
Remote Diagnostic Logs Commands the charger to package its internal fault & hardware logs and upload them to a server URL. Enter target URL in Remote Diagnostic Log Upload above and click Upload Charger Logs. GetDiagnostics
